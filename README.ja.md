# App Restore Rescue

[English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [繁體中文](README.zh-TW.md)

[リリースをダウンロード](https://github.com/dAAAb/app-restore-rescue/releases/latest) · [プライバシー](PRIVACY.md)

iPhone の移行後に復元が進まなくなったアプリを調査し、**明示的に選択した USB 接続のデバイス 1 台に対して、選択したアプリ 1 件だけのアンインストールを要求する**、オープンソースの macOS ユーティリティです。

開発のきっかけは、ホーム画面にも iPhone のアプリ一覧にもアプリが見つからず、App Store からの再ダウンロードが `ASDErrorDomain Code=506`、`Duplicate restoring request` で失敗した事例です。そのアプリを指定したアンインストール要求が完了した後、通常どおりダウンロードできるようになりました。これは解決を確認できた 1 件の事例であり、すべてのダウンロード失敗を解決できるという保証ではありません。

**アンインストールにより、選択したアプリのローカルの書類、下書き、その他の未同期データが完全に削除される可能性があります。** 本ツールは確認手順を備えたアンインストール用ツールです。データを保持したままキャッシュだけを消去するものではなく、iPhone の問題全般を修復するものでもありません。

## ダウンロードと動作要件

- macOS 13 以降。Apple シリコンおよび Intel Mac に対応。
- USB で接続され、ロックが解除されており、利用者がこのコンピュータを信頼済みの iPhone。
- 利用者が別途インストールした `ideviceinstaller` **1.2 以降**と、関連する `libimobiledevice` ツール。本アプリがソフトウェアをインストール・更新することはありません。

すでに Homebrew を利用している場合、依存ツールは次のコマンドでインストールできます。

```sh
brew install ideviceinstaller
```

Homebrew は `libimobiledevice`、`libplist`、`libzip` などの依存関係を処理します。提示される変更内容は、ご自身で確認してください。インストール先は Mac であり、iPhone にアプリをインストールする操作ではありません。[Homebrew の Formula](https://formulae.brew.sh/formula/ideviceinstaller)と[上流プロジェクト](https://github.com/libimobiledevice/ideviceinstaller)を参照してください。

同じ [GitHub Release](https://github.com/dAAAb/app-restore-rescue/releases/latest) から `AppRestoreRescue-vX.Y.Z-macOS-universal.zip` と `SHA256SUMS.txt` をダウンロードします。ダウンロード先のディレクトリで、展開する前に ZIP を検証してください。

```sh
shasum -a 256 -c SHA256SUMS.txt
```

ZIP にはユニバーサル版の `.app`、4 言語の README、ライセンス、プライバシー情報、ビルドのリビジョン情報が含まれます。**サードパーティー製のデバイス操作ツールは同梱していません。**

### macOS のセキュリティ通知

初期リリースには **ad-hoc 署名のみがあり、Apple Developer ID による署名も Apple の公証もありません**。この署名で検証できるのはアプリの整合性であり、Apple が確認した配布者の身元ではありません。初回起動時に macOS がアプリをブロックする場合があります。開くかどうかを決める前に、ソースコードと配布元を確認してください。開くことを選んだ場合は、Apple の案内に従い、表示される場合に限り「プライバシーとセキュリティ → このまま開く」で、このアプリだけを許可してください。Gatekeeper を全体で無効にしないでください。組織が管理する Mac では、その管理ポリシーに従ってください。[Apple の説明](https://support.apple.com/ja-jp/102445)

## 使い方

1. アプリを開き、必要なツールの状態を確認します。自動インストールは行われません。
2. 対象の iPhone を接続してロックを解除し、USB デバイス一覧を更新して、対象を明示的に選択します。識別子は一部を隠して表示されます。どの端末か確信が持てない場合は、ほかの iPhone を取り外してください。
3. 既存のローカルログを読み込むか、短時間のログ監視を開始します。画面に「監視中」と表示されるのを待ってから、iPhone の App Store で、**問題のアプリの雲のダウンロードボタンを手動で 1 回だけ押します**。再試行が成功してインストールが始まる可能性もあります。監視機能自体がボタンを押すことはありません。必要なイベントを記録できたら監視を停止します。すでに適切なログがあれば、再試行は不要です。
4. 候補アプリの識別子と、それに対応する復元エラーを確認します。過去のログに一致があることは手掛かりであり、現在も問題が続いている証明ではありません。ダウンロードボタンが回転するだけでは診断できません。別途確認したバンドル識別子を直接入力することもできます。
5. 選択した対象を検査します。照会するのはそのアプリだけであり、インストール済みアプリ全体の一覧は取得しません。アプリの記録が見つからないことだけでは、復元処理の残留があるとは断定できません。
6. 削除を試すと決めた場合は、デバイスとバンドル識別子を確認し、ローカルデータが失われる可能性を理解したうえで、確認欄に完全一致するバンドル識別子を入力します。送信するのはその 1 件の要求だけです。自動再試行、別デバイスへの切り替え、一括アンインストールは行いません。
7. アンインストール完了の結果を確認したら、iPhone の App Store に戻り、ご自身で再ダウンロードしてください。**元の症状が解消したと確認できるのは、再ダウンロードが成功したときです。**

表示言語は macOS の言語設定に自動的に従い、英語、日本語、韓国語、繁体字中国語（`en`、`ja`、`ko`、`zh-Hant`）に対応します。macOS が優先順位に従って対応言語を選び、アプリごとの言語設定がある場合はそれも反映します。一致する言語がない場合は英語になります。アプリ内に言語選択メニューはありません。macOS の言語設定を変更した後は、アプリを終了して開き直してください。

X のバンドル識別子は `com.atebits.Tweetie2` です。[X 公式の関連ドメイン設定ファイル](https://x.com/.well-known/apple-app-site-association)で確認できます。ほかのアプリの識別子を、表示名から推測しないでください。

## 確認できることと限界

本ツールは、ログに明示された復元関連のエラーを探し、iPhone のインストールサービスに対して、指定した Bundle ID のアンインストールを要求できます。アプリのデータベースを直接編集したり、非公開の coordinator を UUID で取り消したり、全アプリを修復したりするものではありません。残留した復元処理の解消も保証できません。

`Uninstall: Complete` は、デバイス操作ツールが要求の完了を報告したことを示します。App Store からの再ダウンロードを確認したという意味ではありません。要求の送信後にタイムアウトした場合、結果が不明なことがあります。再試行を検討する前に、まず iPhone の状態を確認してください。

iPhone が表示されない場合は、USB ケーブル、ロック解除・信頼の状態、ツールの実行環境を確認してください。サンドボックスや制限されたリモート実行環境では、iPhone が接続されていても macOS のデバイスサービスにアクセスできないことがあります。その回避のためにシステム全体のセキュリティ設定を変更しないでください。

## プライバシーの範囲

- アクセス解析、クラッシュレポートのアップロード、アカウントへのログイン、クラウドバックエンド、自動更新サービスはありません。
- iPhone の診断データを自動で書き出すことはありません。利用者がローカルファイルを選ぶか、明示的にログ監視を開始します。
- 生のログと完全なデバイス識別子は、依頼された操作のためにローカルのメモリ内で使用します。アプリのログファイルとして保存したり、公開レポートに含めたりしません。
- デバイス識別子は一部を隠して表示します。公開プロジェクトの例には、プレースホルダーまたは架空の値を使っています。
- 入力された Bundle ID をシェルで評価しません。`sudo` の実行、依存ツールの自動インストール、サードパーティー製 IPA のインストールも行いません。
- macOS のデバイスサービスへのアクセスが必要なため、配布版では App Sandbox の entitlement を有効にしていません。

macOS、iOS、別途インストールされたデバイス操作ツールは、それぞれシステムログや信頼の記録を管理する場合があります。本プロジェクトは、OS による書き込みが一切発生しないことを保証できません。特にスクリーンショットや診断情報を共有する前に、[PRIVACY.md](PRIVACY.md) で詳しい範囲を確認してください。

## コマンドラインで行う場合

上流のコマンドラインツールを直接使うこともできます。操作の種類とローカルデータが削除されるリスクは同じです。`idevice_id -l` で対象のデバイス識別子を手元で確認し、その出力を公開しないでください。以下のプレースホルダーを、操作したいデバイスの正確な識別子に置き換えます。

```sh
DEVICE_UDID='YOUR_IPHONE_UDID'
APP_BUNDLE_ID='com.atebits.Tweetie2'
ideviceinstaller -u "$DEVICE_UDID" uninstall "$APP_BUNDLE_ID"
```

要求の送信に、ホーム画面上のアイコンは必要ありません。ただし、記録のないアプリの削除を iPhone が受け付けるかどうかは、そのときの状態によります。上流ツールには旧バージョンの構文もありますが、本 GUI は呼び出し方法を限定して検証できるよう、`ideviceinstaller` 1.2 以降を必須にしています。

検証範囲：元の事例では、対象を限定した CLI 操作の成功を確認しました。GUI のテストには架空のログと模擬デバイスサービスを使用しています。ライブ監視の一連の動作は、まだ実機の iPhone で最初から最後まで検証していません。

## 開発とリリース

Swift package にサードパーティー製の Swift 依存パッケージはありません。ユニットテストは架空の入力と模擬デバイスツールを使い、実際の iPhone に接続したり、本物のアンインストール要求を送信したりしてはいけません。

**Swift／Xcode ツールチェーンをすでにインストール・設定済み**の開発用 Mac で、次を実行できます。

```sh
swift test
python3 -m unittest discover -s scripts/tests -v
python3 scripts/privacy_audit.py
bash scripts/build-release.sh 1.0.0
```

ビルドスクリプトは開発者と CI 専用です。arm64 と x86_64 をコンパイルし、ad-hoc 署名付きアプリを作成して両アーキテクチャを検証した後、許可リストにあるアプリとドキュメントだけを ZIP に含めます。ZIP のメタデータは正規化されます。ただし、SDK やコンパイラが変わればバイナリも変わる可能性があります。繰り返し実行できるビルド手順であり、異なるツールチェーン間でのビット単位の一致を保証するものではありません。

GitHub Actions はテストと公開対象ファイルの検査を実行します。`vMAJOR.MINOR.PATCH` タグをプッシュすると、ユニバーサル ZIP と SHA-256 チェックサムを含む **リリースの下書き**が作成されます。メンテナーが実際の成果物、UI、プライバシーの範囲を確認してから公開します。CI は個人の署名証明書、キーチェーン、ローカルの診断アーカイブ、iPhone を使用しません。書き込み権限はリリースジョブだけに与えられ、プルリクエストの CI は読み取り専用です。

公開前には自動検査に加えて、ステージ済みファイルをすべて確認してください。自動検査だけで、任意の文章に個人情報が含まれていないことを証明することはできません。公開 issue には、識別情報を取り除いた必要最小限の説明のみを記載してください。[SECURITY.md](SECURITY.md) を参照してください。
