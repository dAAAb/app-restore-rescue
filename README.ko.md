# App Restore Rescue

[English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [繁體中文](README.zh-TW.md)

[릴리스 다운로드](https://github.com/dAAAb/app-restore-rescue/releases/latest) · [개인정보 보호](PRIVACY.md)

iPhone 마이그레이션 후 복원이 멈춘 앱을 조사하고, **명시적으로 선택한 USB 기기 한 대에서 선택한 앱 하나만 제거하도록 요청하는** 오픈 소스 macOS 유틸리티입니다.

홈 화면과 iPhone 앱 목록에서 앱이 사라지고, App Store 재다운로드가 `ASDErrorDomain Code=506`, `Duplicate restoring request` 오류로 실패한 사례를 계기로 만들었습니다. 해당 앱을 지정한 제거 요청이 완료된 뒤에는 정상적으로 다운로드할 수 있었습니다. 이는 해결이 확인된 하나의 사례이며, 모든 다운로드 실패를 해결한다는 보장은 아닙니다.

**앱을 제거하면 해당 앱의 로컬 문서, 초안, 아직 동기화되지 않은 데이터가 영구적으로 삭제될 수 있습니다.** 이 도구는 확인 절차를 갖춘 앱 제거 도구입니다. 데이터를 보존하면서 캐시만 정리하는 도구나 범용 iPhone 복구 프로그램이 아닙니다.

## 다운로드 및 요구 사항

- macOS 13 이상, Apple Silicon 또는 Intel Mac.
- USB로 연결하고 잠금을 해제했으며, 사용자가 이 컴퓨터를 신뢰하도록 설정한 iPhone.
- 사용자가 별도로 설치한 `ideviceinstaller` **1.2 이상** 및 관련 `libimobiledevice` 도구. 앱은 소프트웨어를 설치하거나 업데이트하지 않습니다.

이미 Homebrew를 사용하고 있다면 다음 명령으로 필요한 도구를 설치할 수 있습니다.

```sh
brew install ideviceinstaller
```

Homebrew는 `libimobiledevice`, `libplist`, `libzip` 등의 의존성을 처리합니다. 제안하는 변경 사항은 직접 확인하세요. 이 명령은 Mac에 도구를 설치하며, iPhone에 앱을 설치하지 않습니다. [Homebrew Formula](https://formulae.brew.sh/formula/ideviceinstaller)와 [업스트림 프로젝트](https://github.com/libimobiledevice/ideviceinstaller)를 참고하세요.

동일한 [GitHub Release](https://github.com/dAAAb/app-restore-rescue/releases/latest)에서 `AppRestoreRescue-vX.Y.Z-macOS-universal.zip`과 `SHA256SUMS.txt`를 다운로드하세요. 다운로드 폴더에서 압축을 풀기 전에 ZIP을 검증합니다.

```sh
shasum -a 256 -c SHA256SUMS.txt
```

ZIP에는 유니버설 `.app`, 네 언어의 README, 라이선스, 개인정보 보호 안내, 빌드 리비전 정보가 포함됩니다. **타사 기기 관리 도구의 실행 파일은 포함하지 않습니다.**

### macOS 보안 알림

초기 릴리스는 **ad-hoc 서명만 적용되어 있으며, Apple Developer ID 서명이나 Apple 공증을 받지 않았습니다**. 이 서명은 앱 번들의 무결성을 확인할 수 있게 하지만, Apple이 확인한 배포자 신원을 보장하지는 않습니다. macOS가 처음 실행할 때 앱을 차단할 수 있습니다. 실행 여부를 결정하기 전에 소스 코드와 배포 출처를 확인하세요. 계속 진행하기로 했다면 Apple 안내에 따라, 해당 옵션이 표시될 때만 **개인정보 보호 및 보안 → 그래도 열기**로 이 앱을 개별 허용하세요. Gatekeeper를 전역으로 비활성화하지 마세요. 조직에서 관리하는 Mac은 해당 관리 정책을 따르세요. [Apple 안내](https://support.apple.com/ko-kr/102445)

## 사용 방법

1. 앱을 열고 필요한 도구의 상태를 확인합니다. 자동으로 설치되는 것은 없습니다.
2. 대상 iPhone을 연결하고 잠금을 해제합니다. USB 기기 목록을 새로 고친 뒤 기기를 명시적으로 선택합니다. 화면에는 식별자 일부만 표시됩니다. 어느 기기인지 확실하지 않다면 다른 iPhone은 분리하세요.
3. 기존 로컬 로그를 가져오거나 짧은 로그 모니터링을 시작합니다. 앱에 “모니터링 중”이 표시될 때까지 기다린 다음, iPhone의 App Store에서 **문제가 있는 앱의 구름 다운로드 버튼을 직접 한 번만 누릅니다**. 재시도가 성공하면 앱 설치가 시작될 수도 있습니다. 모니터링 기능 자체가 버튼을 누르지는 않습니다. 필요한 이벤트를 기록했다면 모니터링을 중지하세요. 적절한 기존 로그가 있다면 다운로드를 다시 시도할 필요가 없습니다.
4. 후보 앱의 식별자와 연결된 복원 오류를 확인합니다. 과거 로그의 일치 기록은 조사 단서일 뿐, 현재도 문제가 있다는 증거는 아닙니다. 다운로드 버튼이 회전하는 현상만으로 원인을 진단할 수 없습니다. 별도로 확인한 번들 식별자를 직접 입력할 수도 있습니다.
5. 선택한 대상을 검사합니다. 모든 설치 앱의 목록이 아니라 해당 앱만 조회합니다. 앱 기록이 없다는 사실만으로 남아 있는 복원 작업이 있다고 단정할 수는 없습니다.
6. 제거를 시도하기로 했다면 기기와 번들 식별자를 확인하고, 로컬 데이터가 삭제될 수 있음을 이해한 뒤, 확인란에 번들 식별자를 정확히 입력합니다. 선택한 대상에 대해서만 요청을 한 번 보냅니다. 자동 재시도, 다른 기기로 전환, 일괄 제거는 하지 않습니다.
7. 제거 완료 결과를 받으면 iPhone의 App Store로 돌아가 직접 앱을 다시 다운로드하세요. **재다운로드가 성공해야 원래 증상이 해결되었다고 확인할 수 있습니다.**

앱의 언어는 macOS 언어 설정을 자동으로 따르며 영어, 일본어, 한국어, 중국어 번체(`en`, `ja`, `ko`, `zh-Hant`)를 지원합니다. macOS는 설정된 우선순위에 따라 지원하는 언어를 선택하며, 앱별 언어를 따로 지정한 경우 그 설정도 반영합니다. 일치하는 언어가 없으면 영어를 사용합니다. 앱 내부에 별도 언어 선택 메뉴는 없습니다. macOS 언어 설정을 바꾼 뒤에는 앱을 종료하고 다시 여세요.

X의 번들 식별자는 `com.atebits.Tweetie2`이며, [X 공식 연결 도메인 설정 파일](https://x.com/.well-known/apple-app-site-association)에서 확인할 수 있습니다. 다른 앱의 식별자를 표시 이름만 보고 추측하지 마세요.

## 확인할 수 있는 내용과 한계

이 도구는 로그에 명확히 기록된 복원 관련 오류를 찾고, iPhone의 설치 서비스에 지정한 Bundle ID의 제거를 요청할 수 있습니다. 앱 데이터베이스를 직접 수정하거나 비공개 coordinator를 UUID로 취소하지 않으며, 모든 앱을 복구하거나 남아 있는 복원 작업이 반드시 정리된다고 보장하지 않습니다.

`Uninstall: Complete`는 기기 관리 도구가 요청 완료를 보고했다는 의미입니다. App Store에서 재다운로드를 검증했다는 뜻은 아닙니다. 제거 요청을 보낸 후 시간 초과가 발생했다면 결과를 알 수 없는 상태일 수 있습니다. 재시도를 고려하기 전에 먼저 iPhone 상태를 확인하세요.

iPhone이 보이지 않으면 USB 케이블, 잠금 해제 및 신뢰 상태, 도구 실행 환경을 확인하세요. 샌드박스나 제한된 원격 환경에서는 iPhone이 연결되어 있어도 macOS 기기 서비스에 접근하지 못할 수 있습니다. 이를 해결하려고 시스템 전체의 보안 설정을 변경하지 마세요.

## 개인정보 보호 범위

- 사용 분석, 충돌 보고서 업로드, 계정 로그인, 클라우드 백엔드, 자동 업데이트 서비스가 없습니다.
- iPhone 진단 자료를 자동으로 내보내지 않습니다. 사용자가 로컬 파일을 선택하거나 명시적으로 모니터링을 시작합니다.
- 원본 로그와 전체 기기 식별자는 요청한 작업에 필요한 동안 로컬 메모리에서 사용합니다. 앱 로그 파일로 따로 저장하거나 공개 보고서에 포함하지 않습니다.
- 화면의 기기 식별자는 일부를 가려 표시합니다. 공개 프로젝트의 예시에는 자리표시자나 가상의 값을 사용합니다.
- 입력한 Bundle ID를 셸에서 평가하지 않습니다. `sudo` 실행, 의존성 자동 설치, 타사 IPA 설치도 하지 않습니다.
- macOS 기기 서비스에 접근해야 하므로, 배포 앱에는 App Sandbox entitlement가 적용되어 있지 않습니다.

macOS, iOS, 별도로 설치한 기기 관리 도구는 자체 시스템 로그나 신뢰 기록을 유지할 수 있습니다. 이 프로젝트는 운영체제의 쓰기 작업이 전혀 발생하지 않는다고 보장할 수 없습니다. 특히 스크린샷이나 진단 자료를 공유하기 전에 [PRIVACY.md](PRIVACY.md)에서 전체 범위를 확인하세요.

## 명령줄로 직접 실행하는 방법

업스트림 명령줄 도구를 직접 사용할 수도 있습니다. 같은 종류의 작업이며 로컬 데이터 삭제 위험도 같습니다. `idevice_id -l`로 대상 기기 식별자를 개인적으로 확인하고, 그 출력을 공개하지 마세요. 아래 자리표시자를 정확한 대상 기기 식별자로 바꿉니다.

```sh
DEVICE_UDID='YOUR_IPHONE_UDID'
APP_BUNDLE_ID='com.atebits.Tweetie2'
ideviceinstaller -u "$DEVICE_UDID" uninstall "$APP_BUNDLE_ID"
```

요청을 보내기 위해 홈 화면에 아이콘이 있어야 하는 것은 아닙니다. 다만 기록이 없는 앱의 제거를 iPhone이 받아들이는지는 당시 상태에 따라 달라집니다. 업스트림 도구에는 이전 버전의 명령 구문도 있지만, 이 GUI는 호출 방식을 제한하고 검증하기 위해 `ideviceinstaller` 1.2 이상을 요구합니다.

검증 범위: 원래 사례에서는 특정 대상을 지정한 CLI 작업의 성공을 확인했습니다. GUI 테스트는 가상의 로그와 모의 기기 서비스를 사용합니다. 실시간 모니터링의 전체 과정은 아직 실제 iPhone에서 처음부터 끝까지 검증하지 않았습니다.

## 개발 및 릴리스

Swift package에는 타사 Swift 의존성이 없습니다. 단위 테스트는 가상 입력과 모의 기기 도구를 사용하며, 실제 iPhone에 연결하거나 실제 제거 명령을 실행해서는 안 됩니다.

**Swift/Xcode 도구 체인이 이미 설치되고 설정된** 개발용 Mac에서 다음 명령을 실행할 수 있습니다.

```sh
swift test
python3 -m unittest discover -s scripts/tests -v
python3 scripts/privacy_audit.py
bash scripts/build-release.sh 1.0.0
```

빌드 스크립트는 개발자와 CI 전용입니다. arm64와 x86_64 실행 파일을 컴파일하고, ad-hoc 서명된 앱을 만든 다음, 두 아키텍처를 검증하고 허용 목록에 있는 앱 및 문서 파일만 압축합니다. ZIP 메타데이터는 정규화됩니다. SDK나 컴파일러가 달라지면 바이너리가 달라질 수 있습니다. 반복 가능한 빌드 절차이며, 서로 다른 도구 체인에서 비트 단위로 동일한 결과를 보장한다는 뜻은 아닙니다.

GitHub Actions는 테스트와 공개 대상 파일 검사를 실행합니다. `vMAJOR.MINOR.PATCH` 태그를 푸시하면 유니버설 ZIP과 SHA-256 체크섬을 포함한 **릴리스 초안**이 생성됩니다. 유지 관리자가 실제 배포 파일, UI, 개인정보 보호 범위를 확인한 후 공개합니다. CI는 개인 서명 인증서, 키체인, 로컬 진단 아카이브, iPhone을 사용하지 않습니다. 쓰기 권한은 릴리스 작업에만 부여되며, 풀 리퀘스트 CI는 읽기 전용입니다.

공개 전에는 자동 검사와 함께 스테이징된 모든 파일을 검토하세요. 자동 검사만으로 모든 문장에 개인정보가 없음을 증명할 수는 없습니다. 공개 issue에는 식별 정보를 제거한 최소한의 설명만 작성하세요. [SECURITY.md](SECURITY.md)를 참고하세요.
